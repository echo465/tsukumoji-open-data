# Tsukumoji — open stroke & dictionary data

Share-alike data bundles shipped inside **Tsukumoji** (Nestling Studios LLC), a cozy
kana / N5-level kanji learning game. Published to satisfy the ShareAlike terms of the
sources below; everything in this repository is free to reuse under the licence stated
in each directory. The game itself is a separate, proprietary work — only these
adaptations are share-alike (see the CC FAQ on collections vs adaptations).

| Directory | Contents | Licence |
|---|---|---|
| `kanjivg-bysa/` | 195 unmodified KanjiVG SVGs (46 hiragana, 46 katakana, 103 N5-level kanji) + our derived stroke templates `kana-strokes.json` / `kanji-strokes.json` (32-point normalized strokes + raw path data) | **CC BY-SA 3.0** — © Ulrich Apel / KanjiVG contributors; adaptations © Nestling Studios LLC. Full text in `kanjivg-bysa/COPYING`. |
| `edrdg-bysa/` | N5 extracts of KANJIDIC2 (`kanjidic2-n5.json`: 103 kanji — meanings, readings, stroke counts) and JMdict (`jmdict-n5.json`: 300 words — verbatim glosses) | **CC BY-SA 4.0** under the EDRDG licence (`edrdg-bysa/EDRDG-LICENCE.txt`). |

Per-directory `ATTRIBUTION.md` files describe exactly what was fetched and what was
derived. The house-authored parts of the game (keywords, mnemonics, curriculum) are
NOT in this repository and are not share-alike.

## Provenance

Generated by the Tsukumoji content pipeline `tools/content/build-kana-db.py`
0.4.0 (fetch → derive → validate, all-or-nothing). This snapshot corresponds to
game build **0.5.1** (source commit `da88d6d`). Extracts are refreshed in the same
release cycle as any game update that regenerates them.
