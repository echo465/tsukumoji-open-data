ン U+30F3; kanji e.g. `04f11.svg` = 休 U+4F11).

## What was derived

`kana-strokes.json` and `kanji-strokes.json` (generated by
`tools/content/build-kana-db.py`) are **adaptations** of these SVGs: per-glyph
ordered stroke lists with each stroke resampled to 32 normalized points, plus
the raw SVG path data for ink rendering. As adaptations of a CC BY-SA 3.0
work, both JSON files are themselves licensed **CC BY-SA 3.0**.

## Isolation rule

Everything in this directory is CC BY-SA 3.0 and is destined for publication
in the studio's public BY-SA assets repository. **Nothing outside this
directory may embed or copy its contents.** The game content DB
(`data/content/kana-db.json`) references strokes only by opaque `strokeRef`
identifiers and contains no KanjiVG-derived geometry.
